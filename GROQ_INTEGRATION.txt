QUICK START
================================================================================

1. SET ENVIRONMENT VARIABLE:
   export GROQ_API_KEY="your-api-key-from-console.groq.com"

2. USE IN CODE (3 OPTIONS):

   Option A - Utility Function (Recommended):
   ---
   from utils.error_analyzer import analyze_error
   
   result = analyze_error("Your error message")
   print(result['explanation'])
   print(result['cause'])
   print(result['fix'])

   Option B - Safe Version (No Exceptions):
   ---
   from utils.error_analyzer import get_error_analysis_safe
   
   result = get_error_analysis_safe("Error message")
   # Always returns valid dict, never throws

   Option C - Direct Service:
   ---
   from services.groq_ai_service import GroqAIService
   
   service = GroqAIService()
   result = service.analyzeError("Error message")

3. API ENDPOINT:
   curl -X POST http://localhost:5000/api/errors/analyze \
     -H "Content-Type: application/json" \
     -d '{"message":"Your error here"}'

}

Example response:
{
  "explanation": "TypeError occurs when accessing property of undefined value",
  "cause": "Variable was not properly initialized before use",
  "fix": "Check initialization logic and add null/undefined checks"

API ENDPOINTS SUMMARY
================================================================================

POST /api/errors/analyze
  Body: {"message": "error text"}
  Response: {explanation, cause, fix}
  Status: 200 on success, 400/500 on error

POST /api/errors/batch
  Body: {"errors": ["error1", "error2"]}
  Response: {"results": [{message, explanation, cause, fix}]}
  Status: 200 on success, 400/500 on error

GET /api/errors/health
  Response: {status, service, model}
  Status: 200 if OK, 503 if unavailable
